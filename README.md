# Student Profile UI - Flutter

A clean, modern, and minimal **Student Profile UI** template built with Flutter[cite: 1]. This UI layout is specifically designed for educational, e-learning, or quiz-based mobile applications to present student stats, contact information, and app controls in an intuitive format[cite: 1].

## ✨ Features

- **Profile Header:** Displays student initials inside a circular avatar, full name ("Syed Mudassir"), and role ("Flutter Developer")[cite: 1].
- **Performance Metrics:** Quick overview cards displaying:
  - Total Quizzes Taken (e.g., 12)[cite: 1]
  - Average Score Percentage (e.g., 82%)[cite: 1]
  - Current Class Rank (e.g., #5)[cite: 1]
- **Details Card:** Cleanly formatted list items for personal information including Email, School Name, and Joining Date[cite: 1].
- **Action Items:** Outlined option tiles for Notifications and Logout[cite: 1].
- **Clean UI/UX:** Styled using soft rounded borders (`BorderRadius`), custom icons, and a lightweight color scheme[cite: 1].
